# MentalEdge V16 – Clean Integration

Basis ist ausschließlich die vom Nutzer bestätigte funktionierende V10.

Neu sauber in diese Basis integriert:
- dauerhaft sichtbarer Schwerpunkt + Cue über Tagesgrenzen
- jeder neue Kalendertag verlangt einen frischen Check-in
- Check-in verändert den Schwerpunkt nicht automatisch
- Mentaltraining → echter Sporttransfer → kurze Auswertung
- Training: Zielumsetzung + Hauptstörfaktor
- Wettkampf: zusätzlich wahrgenommener Druck
- maximal eine adaptive Zusatzfrage bei nicht stabilem Transfer
- Fortschritt über Sessions / Transfers / konsequente Anwendungen statt XP
- Progression: Grundlage → Ablenkung → sportnaher Transfer
- Zoom/Pinch-Zoom im Viewport deaktiviert

Alte V10-Vorbereitungs- und umfangreiche Reflexionslogik wurde entfernt bzw. ersetzt; nicht parallel angehängt.
